# Red-Black Tree Insertion Simulator

An interactive educational WebApp for demonstrating **Red-Black Tree insertion** for DAA.

## 🚀 Live Demo

https://red-black-tree.hatchable.site

## ✨ Features

- Interactive value insertion
- Red/Black node visualization
- Automatic recoloring
- Left and right rotations
- Step-by-step insertion
- Play/Pause animation
- Random 7-node sequence
- Reset tree
- Node count
- Tree height
- Rotation count
- Black height
- Red-Black Tree properties
- Time and space complexity information
- Responsive interface

## 🧠 Red-Black Tree Rules

1. Every node is either red or black.
2. The root is always black.
3. Every NIL leaf is black.
4. A red node cannot have a red child.
5. Every path from a node to its descendant NIL leaves has the same black height.

## ⏱ Complexity

| Operation | Complexity |
|---|---|
| Search | O(log n) |
| Insertion | O(log n) |
| Space | O(n) |

## 🛠 Technology

## 🎓 Academic Use

This project is designed as a **DAA / Data Structures educational demonstration** for Red-Black Tree insertion.

Try this sequence:

```text
10 → 20 → 30
```

The insertion of `30` demonstrates balancing through rotation and recoloring.
